# Contribution boundary

## Existing neuroscience research

The separate Audiovisual EEG Encoding Study contains source-audited EduGage media mappings, timing adapters, a four-lecture EEG recorded-voltage baseline, and a stimulus-only inference demonstration. It remains unchanged. Its earlier outcome is recorded voltage, not attention, comprehension, or quiz correctness.

## New product repository

This repository adds the educator workflow, versioned lesson and assessment records, private local media storage, persisted jobs and SSE, authored student action traces, source-linked content checks, versioned repair packages, evidence labels, sanitized HTML export, and a frozen **proposed** behavioral protocol. These simulations do not constitute human validation.

No participant data, restricted media, checkpoints, model weights, or research outputs are committed here. The adapter checks storage readiness and defines cache identity; it does not import data or claim calibrated predictions.
